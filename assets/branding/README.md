# Branding assets

Place your brand assets here and point `config.yaml` at them:

- `logo.png` — transparent-background PNG, used on the intro and outro cards
  (`brand.logo_path`).
- An optional QR code or app-store badge image for the outro CTA
  (`brand.qr_code_path`). If omitted, a placeholder outline box with
  "QR / App badge" text is drawn instead so the layout is always complete.

Recommended: square logo, at least 512x512px, transparent PNG.
